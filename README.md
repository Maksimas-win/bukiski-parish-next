# Приходской сайт Букишки

Самостоятельная статическая версия сайта храма Рождества Христова: 30 основных страниц на RU/LT/EN, сохранённые материалы двух сайтов, расписание, контакты, библиотека и локальная подготовка записок. Исходники подготовлены 10 октября 2026 года. Рабочие сайты и существующие GitHub-репозитории не изменены.

**Статус: тестовая версия для проверки приходом.** Репозиторий: [Maksimas-win/bukiski-parish-next](https://github.com/Maksimas-win/bukiski-parish-next). Адрес тестовой публикации: [GitHub Pages](https://maksimas-win.github.io/bukiski-parish-next/). Workflow Pages всегда собирает сайт с отключённой индексацией. Перед основным запуском требуется проверить переводы, богослужебную информацию, сведения об операторе данных и перенос старого домена. Все четыре исходных PDF/DOC восстановлены без изменения содержимого; статьи скачивают их через страницы с `noindex`, без прямых индексируемых PDF/DOC-адресов в тестовой публикации. Источники и контрольные суммы указаны в [реестре документов](content/source-documents.json).

## Запуск

Установите поддерживаемую Node.js 24 LTS. Сторонних npm-зависимостей нет, `npm install` не требуется.

```sh
npm run check
npm run dev
```

Откройте адрес, который напечатает сервер, обычно `http://127.0.0.1:4173/`. Не открывайте шаблон `index.html` двойным щелчком: готовая версия находится в `dist/` и использует локальные модули.

## Что входит

- Главная, расписание, история, таинства, жизнь прихода, контакты, библиотека, записки, помощь, конфиденциальность — на трёх языках.
- 127 исходных страниц: 92 с `.net` и 35 с `.org`. Тексты восстановлены также из 21 встроенного блока старого конструктора. Реестр содержит URL, язык, назначение, объём текста и контрольную сумму.
- 160 сохранённых изображений; главная использует три оптимизированных WebP-размера реальной фотографии храма.
- 74 события из опубликованного приходского календаря. Расписание отфильтровывает прошедшие службы, отмены и события без определённого времени, различает часовые смещения Вильнюса и предупреждает об устаревшем источнике.
- Локальная форма записки: проверка имён, предпросмотр, печать, скачивание и очистка. **Записка не отправляется в приход.**
- Переключение языка сохраняет текущий основной раздел. Статьи остаются на языке оригинала; существующие PL-страницы и GPM-материалы на DE/UK сохранены как архив.
- Поиск по названиям и описаниям, фильтр языка, мобильное меню, крупный шрифт, контраст, клавиатурное управление и печатная версия.
- Canonical, hreflang, OpenGraph, sitemap, robots, настоящая страница 404 и микроразметка Church на контактах.
- CSP без unsafe-inline, отсутствие внешних скриптов, аналитики и автоматически загружаемых карт.

## Структура

```text
index.html                 HTML-шаблон документа
assets/css/site.css        Стили и адаптивная вёрстка
assets/js/app.js           Небольшие улучшения интерфейса
assets/js/domain.js        Проверка дат, имён и URL
assets/img/                Оптимизированная фотография и архив
assets/fonts/              Политика шрифтов, без внешних запросов
content/                   Словари, настройки, исходные тексты и расписание
scripts/                   Сборка, предпросмотр, импорт расписания
tests/                     Проверки содержимого, безопасности и календаря
deploy/                    Правила для старого домена
.github/workflows/         Проверка проекта и ручное развёртывание Pages
dist/                      Собранный сайт; не коммитится
```

## Публикация и сопровождение

Предложенный новый репозиторий: **Maksimas-win/bukiski-parish-next**. Он не создан. Существующий `Maksimas-win/bukiski-hram-org` оставлен без изменений. Сначала удобно создать отдельный приватный репозиторий для проверки прав на архивные материалы и переводы.

Для основного домена рекомендуется **GitHub как хранилище исходников + статический Apache-хостинг, например Hostinger**. Это сохраняет `.html`-адреса и позволяет выставить серверные заголовки и HTTP 301. GitHub Pages также поддержан; его ограничения описаны отдельно.
