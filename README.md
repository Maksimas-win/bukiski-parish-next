# Приходской сайт Букишки

Статический сайт храма Рождества Христова в Букишках: основные страницы на шести языках (RU, LT, EN, PL, DE, UK), сохранённые материалы двух прежних сайтов, расписание богослужений, контакты, библиотека и подготовка записок на устройстве посетителя.

**Статус: рабочий сайт на [bukiski-hram.net](https://bukiski-hram.net/).** Репозиторий: [Maksimas-win/bukiski-parish-next](https://github.com/Maksimas-win/bukiski-parish-next). Публикация: `main` → GitHub Actions (`production.yml`) → ветка `hostinger-production` → Hostinger. Тестовая копия для просмотра правок: [GitHub Pages](https://maksimas-win.github.io/bukiski-parish-next/), всегда собирается с отключённой индексацией. Сайт `bukiski-hram.org` работает отдельно (репозиторий `bukiski-hram-org`) и остаётся источником расписания; решение о его дальнейшей роли принимает приход — варианты описаны в [DEPLOYMENT.md](docs/DEPLOYMENT.md). Обслуживание, мониторинг, копии и восстановление — в [MAINTENANCE.md](MAINTENANCE.md), краткая памятка владельцу — в [docs/OWNER.md](docs/OWNER.md).

## Запуск

Нужна Node.js 22 или новее (в CI используется 24 LTS). Сторонних npm-зависимостей нет, `npm install` не требуется.

```sh
npm run check   # сборка в dist/ и все тесты
npm run dev     # предпросмотр на http://127.0.0.1:4173/
```

Не открывайте шаблон `index.html` двойным щелчком: готовый сайт находится в `dist/` и использует локальные модули.

## Что входит

- **Главная, расписание, история, таинства, жизнь прихода, контакты, библиотека, записки, помощь, конфиденциальность** — на шести языках (русский, литовский, английский, польский, немецкий, украинский), с переключением языка на ту же страницу.
- **Расписание** из приходского календаря: группировка по месяцам, фильтр праздников, отметки «сегодня» и «завтра», файл календаря для отдельной службы и для всего расписания, подписка на календарь в Google, Apple и Outlook. Прошедшие службы скрываются, устаревший снимок сопровождается предупреждением. Тестовая публикация обновляет расписание каждые шесть часов.
- **Библиотека**: 96 материалов из 127 сохранённых страниц (92 с `.net`, 35 с `.org`). Фильтр по языку, поиск по заголовкам и, по желанию посетителя, по полным текстам с подсветкой найденного. В статьях сохранены списки и заголовки, есть оглавление, время чтения, просмотр фотографий.
- **Записка**: проверка имён по строкам, живой предпросмотр, **отправка в приход онлайн** (та же форма, что на прежнем .net, только после согласия), печать, скачивание и копирование. Имена не сохраняются в браузере и стираются при уходе со страницы.
- **Таинства и требы**: поминовения на Литургии, требы по согласованию, настоятель, телефон и WhatsApp.
- **Контакты**: автобусные маршруты и остановка, дорога на автомобиле, время открытия храма, соцсети прихода.
- **Фотографии**: настоящие снимки храма с просмотром на весь экран.
- **История**: хронология и полные статьи прихода об истории храма и рода Божеряновых.
- **Настройки чтения**: светлое и тёмное оформление, крупный текст, высокая контрастность. Сайт полностью читается и без JavaScript.
- **Поиск и обмен ссылками**: canonical, hreflang, OpenGraph, sitemap, robots, настоящая страница 404, микроразметка Church на странице контактов.
- **Защита**: CSP без `unsafe-inline`, никаких внешних скриптов, шрифтов, аналитики и встроенных карт.

## Структура

```text
index.html            Шаблон HTML-документа
styles/               Стили по частям; сборка объединяет их в assets/css/site.css
assets/js/            Клиентский код: app.js, ui/, features/, общие правила в domain.js
assets/fonts/         Source Sans 3 и Source Serif 4 Display (SIL OFL), без внешних запросов
assets/img/           Фотография храма, значки; web/ — оптимизированные копии архива
assets/documents/     Восстановленные PDF/DOC (оригиналы)
content/              Тексты интерфейса, настройки, исходные страницы, расписание
scripts/build.mjs     Сборка; логика разбита по модулям в scripts/lib/
scripts/lib/pages/    По модулю на тип страницы
scripts/tools/        Вспомогательные задачи сопровождения (оптимизация изображений)
tests/                Проверки содержимого, вёрстки, клиентского кода и календаря
deploy/               Перенаправление bukiski-hram.org на основной домен
.github/workflows/    Проверка проекта и публикация тестовой версии
dist/                 Собранный сайт; не коммитится
```

Подробнее: [архитектура и безопасность](docs/ARCHITECTURE.md).
