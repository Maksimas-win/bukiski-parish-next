# Приходской сайт Букишки

Статический сайт храма Рождества Христова в Букишках: 30 основных страниц на RU/LT/EN, сохранённые материалы двух прежних сайтов, расписание богослужений, контакты, библиотека и подготовка записок на устройстве посетителя.

**Статус: тестовая версия для проверки приходом.** Репозиторий: [Maksimas-win/bukiski-parish-next](https://github.com/Maksimas-win/bukiski-parish-next). Тестовый адрес: [GitHub Pages](https://maksimas-win.github.io/bukiski-parish-next/). Тестовая публикация всегда собирается с отключённой индексацией. Перед основным запуском нужно проверить переводы, богослужебную информацию, сведения об операторе данных и перенос старого домена: см. [RELEASE.md](docs/RELEASE.md). Рабочие сайты `bukiski-hram.org` и `bukiski-hram.net` этой работой не изменяются.

## Запуск

Нужна Node.js 22 или новее (в CI используется 24 LTS). Сторонних npm-зависимостей нет, `npm install` не требуется.

```sh
npm run check   # сборка в dist/ и все тесты
npm run dev     # предпросмотр на http://127.0.0.1:4173/
```

Не открывайте шаблон `index.html` двойным щелчком: готовый сайт находится в `dist/` и использует локальные модули.

## Что входит

- **Главная, расписание, история, таинства, жизнь прихода, контакты, библиотека, записки, помощь, конфиденциальность** — на трёх языках, с переключением языка на ту же страницу.
- **Расписание** из приходского календаря: 74 подтверждённые службы, группировка по месяцам, фильтр праздников, отметки «сегодня» и «завтра», файл календаря для отдельной службы и для всего расписания. Прошедшие службы скрываются, устаревший снимок сопровождается предупреждением. Тестовая публикация обновляет расписание каждые шесть часов.
- **Библиотека**: 94 материала из 127 сохранённых страниц (92 с `.net`, 35 с `.org`). Фильтр по языку, поиск по заголовкам и, по желанию посетителя, по полным текстам с подсветкой найденного. В статьях сохранены списки и заголовки, есть оглавление, время чтения, просмотр фотографий.
- **Записка**: проверка имён по строкам, живой предпросмотр, печать, скачивание и копирование. **Записка не отправляется в приход**, имена не сохраняются и стираются при уходе со страницы.
- **Настройки чтения**: светлое и тёмное оформление, крупный текст, высокая контрастность. Сайт полностью читается и без JavaScript.
- **Поиск и обмен ссылками**: canonical, hreflang, OpenGraph, sitemap, robots, настоящая страница 404, микроразметка Church на странице контактов.
- **Защита**: CSP без `unsafe-inline`, никаких внешних скриптов, шрифтов, аналитики и встроенных карт.

## Структура

```text
index.html            Шаблон HTML-документа
styles/               Стили по частям; сборка объединяет их в assets/css/site.css
assets/js/            Клиентский код: app.js, ui/, features/, общие правила в domain.js
assets/fonts/         Source Sans 3 и Source Serif 4 Display (SIL OFL), без внешних запросов
assets/img/           Фотография храма, значки; web/ — оптимизированные копии архива
assets/documents/     Восстановленные PDF/DOC (оригиналы)
content/              Тексты интерфейса, настройки, исходные страницы, расписание
scripts/build.mjs     Сборка; логика разбита по модулям в scripts/lib/
scripts/lib/pages/    По модулю на тип страницы
scripts/tools/        Вспомогательные задачи сопровождения (оптимизация изображений)
tests/                Проверки содержимого, вёрстки, клиентского кода и календаря
deploy/               Правила перенаправления для старого домена
.github/workflows/    Проверка проекта и публикация тестовой версии
dist/                 Собранный сайт; не коммитится
```

Подробнее: [архитектура и безопасность](docs/ARCHITECTURE.md).
