Проверены заголовки и содержимое трёх PDF, все 23 страницы визуального предпросмотра (включая DOC), формат файлов и отсутствие шифрования PDF. В Word не обнаружены хранилища VBA/Macros, в PDF — JavaScript, запускаемые команды и вложенные файлы. Это структурная проверка, а не антивирусная сертификация.

Тест сборки проверяет все 15 мест, подписи файлов, размеры, SHA-256 и точное совпадение файлов в исходниках и сборке. Прежние пометки о недоступности автоматически исчезают при наличии локальной копии.

## Индексация тестовой версии

Документы публикуются только внутри HTML-страниц RU/LT/EN с явным `noindex,nofollow`. Например: [скачать бланки записок](https://maksimas-win.github.io/bukiski-parish-next/ru/documents/blanki-zapisok.html). Страницы загрузки отсутствуют в sitemap. Файлы PDF/DOC из `assets/documents/` исключены из сборки; их прежние публичные URL на GitHub Pages отвечают HTTP 404.

Обычный клик по ссылке в статье загружает HTML-страницу документа в фоне. Модуль JavaScript извлекает исходные байты из инертного `template`, проверяет размер, формат и SHA-256, затем сохраняет PDF или DOC через временный `blob:` URL в браузере. Постоянного HTTP-адреса PDF/DOC больше нет. Правой кнопкой или с Ctrl/Cmd можно открыть отдельную страницу загрузки с обычной кнопкой. Для скачивания требуется JavaScript; при его отключении показано понятное сообщение. На ошибке соединения можно повторить попытку. Имена и содержимое документов не отправляются внешним службам и не сохраняются в localStorage.

Здесь запрет индексации обеспечивается `noindex` на реально обслуживаемом HTML, а не `nofollow`, расширением файла или кодированием Base64. Это позволяет сохранить GitHub Pages без сервера, аккаунтов и отдельной платформы. Все байты оригиналов остаются неизменными. Автоматическая проверка после публикации проверяет настоящие HTTP 404 четырёх прежних адресов и HTTP 200 / `noindex` / контрольные суммы 12 языковых страниц загрузки.

Если прежний прямой адрес уже попал в поиск, удаление из результатов происходит после повторного обхода поисковой системой, а не мгновенно. Этот механизм касается тестовой публикации Pages. Он не ограничивает доступ к исходному публичному репозиторию и не удаляет из поиска документы на действующих сайтах: они не изменялись. Noindex — указание поисковым системам, а не защита паролем.

Основание: [правила noindex для HTML и не-HTML ресурсов](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag), [удаление контента из поиска](https://developers.google.com/search/docs/crawling-indexing/control-what-you-share). Для будущего размещения прямых PDF/DOC на Apache или другом хостинге с настройкой заголовков следует использовать `X-Robots-Tag: noindex`; на GitHub Pages такие прямые адреса не публикуются.
